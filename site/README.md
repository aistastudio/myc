# site/ — сайт проекта на GitHub Pages

Страница на двух языках с графиками. Публикуется на
<https://aistastudio.github.io/myc/>.

## Откуда публикуется и почему именно так

Действием `.github/workflows/pages.yml` из каталога `site/` — не из `docs/` и
не из ветки `gh-pages`.

`docs/` — рабочий каталог: восемь документов проектирования и 36 отчётов о
замерах. Режим Pages «из папки /docs» опубликовал бы всё это как корень сайта и
потребовал бы положить туда `docs/index.html`: витрина перемешалась бы с
внутренними записями, а Jekyll попытался бы обработать markdown отчётов.

Ветка `gh-pages` завела бы вторую копию содержимого в истории и ручной шаг
публикации — источник и опубликованное расходятся ровно в тот день, когда про
ручной шаг забыли.

Публикация действием оставляет один источник и, главное, даёт прогнать
`site/build.ts` прямо в публикации: расхождение числа с артефактом замера роняет
шаг сборки, и сайт с неверным числом не выходит наружу.

## Устройство

| файл | что это |
|---|---|
| `measurements.json` | **единственный источник чисел.** У каждой записи есть `command` — команда, которой число повторяют |
| `build.ts` | сверяет `measurements.json` с артефактами репозитория и выпускает `data.js`; при расхождении падает |
| `data.js` | сгенерирован, руками не править |
| `index.html` | разметка и весь текст на обоих языках сразу |
| `app.js` | отрисовка графиков из `data.js`; ни одного числа о продукте в самом коде |
| `styles.css` | палитра и правила графиков |

## Работа

```bash
bun run site/build.ts            # сверить числа и выпустить data.js
bun run site/build.ts --check    # только сверить, ничего не писать
```

Страница открывается и просто файлом (`site/index.html` в браузере): сети она не
трогает, внешних библиотек нет, данные приходят обычным `<script src="data.js">`.

## Как добавить или поправить число

1. Прогоните команду замера.
2. Перенесите её вывод в `measurements.json` вместе с полем `command`.
3. `bun run site/build.ts` — если число расходится с артефактом, скрипт скажет,
   с каким именно и на сколько.

Числа, у которых артефакта в репозитории нет (размер пакета, импорт из beads,
счёт по вехам), обязаны нести команду: её отсутствие — тоже ошибка сборки.

## Языки

Обе языковые половины лежат в DOM одновременно (`<span lang="en">` и
`<span lang="ru">`), переключатель прячет одну средствами CSS. Поэтому смена
языка ничего не перерисовывает, никуда не переходит и не теряет позицию
прокрутки; выбор запоминается в `localStorage` и отражается в `?lang=`.
