# `myc doctor` — команда, на которую ссылались 24 раза (memory-ryk2t5pft1mh)

## Что сделано

**1. Команда `myc doctor`** (`packages/cli/src/commands/doctor.ts`, зарегистрирована в `register.ts`),
три раздела — ровно те, что уже назывались в коде: `--schema`, `--recount`, `--hooks`; без флагов все три.

Главное решение: **база открывается БЕЗ миграций** (`openDriver` напрямую, не `openStore`).
Иначе единственный сценарий, ради которого команду зовут, был бы единственным, где она не работает:
`precond.schema` советует `myc doctor --schema`, а `openStore` на той же базе бросил бы тот же
`precond.schema`. Проверено живьём (см. ниже).

**Четыре исхода вместо двух** — `ok` / `drift` / `не знаю` / `н/д`. Ненулевой выход даёт только `drift`.
`не знаю` — это «не проверяли», `н/д` — «в этой сборке проверять нечего» (хук на команду,
которой в сборке нет; `myc wire` такой хук намеренно не ставит).

- `--schema`: три таблицы учёта, а не одна (базовая, векторная, swarm — у каждой свой набор миграций).
  Первый живой прогон это и показал: без разделения 8 таблиц swarm читались как «лишние объекты».
  Сверка объектов вынесена в `packages/store-sqlite/src/schema-diff.ts` и **переиспользуется**
  `schema-parity.test.ts` — логика не продублирована, тот тест переписан на общий модуль.
- `--recount`: `open_blockers`, `anc_blockers` (готовые drift-запросы `GraphStore`) и `parent_closure`.
  Замыкание сверяется **настоящей `applyRebuild`** внутри транзакции, которая гарантированно
  откатывается: своя копия рекурсивного CTE была бы вторым определением истины. doctor не чинит.
- `--hooks`: сработавшие (число, время, статус, агент), не поставленные (с причиной) и «не знаю».
  Ограничение из memory-q9k2zxfx2mcm соблюдено буквально: `SELF_REPORTING_HOOKS` в `counters.ts`
  содержит ровно `pre-compact`, поэтому пустой счётчик у `pre-compact` — «не срабатывал ни разу»,
  а у `session-start` — «не знаю: себя не отмечает». Разница проверена тестом.

**2. `myc self-update` — команду НЕ заводил, совет заменил.** Обоснование: автообновление здесь не
недоделка, а зафиксированное решение (докстрок `update-check.ts`, п. 3 — подмена бинаря под
работающим агентом меняет поведение посреди сессии). Теперь печатается
``Обновите бинарь: `bun install -g @aistastudio/myc` (что именно опубликовано — покажет `myc version --check`)``.
Обе команды проверены живьём в песочнице (`BUN_INSTALL=<tmp> bun install -g @aistastudio/myc` → exit 0,
бинарь на месте; `bun add -d @aistastudio/myc@latest` → exit 0, `0.1.1` в package.json).
Строка вынесена в `SCHEMA_UPGRADE_HINT` и **сверяется тестом** с `UPGRADE_COMMAND` из `myc version` —
двух разных команд обновления в одном продукте быть не может.
Замечание по смежной задаче memory-md2zqztzw6w4: в реестре npm сейчас `0.1.1`, то есть сборка из
исходников новее опубликованной, и `myc version --check` честно это скажет («эта сборка новее»).

**3. Сторож** — `packages/cli/src/advised-commands.test.ts`. Собирает из ВСЕХ не-тестовых `.ts`
(`packages/`, `scripts/`) строковые литералы (посимвольный разбор: комментарии вырезаются,
`${…}` обрывает литерал) и требует, чтобы каждая названная команда была в реестре.
Совет узнаётся по двум признакам: обратные кавычки внутри фразы **или** литерал целиком —
командная строка (`hint: "myc doctor --schema"`). Без этого правила было 9 ложных срабатываний
на английской прозе («myc instead of TodoWrite», «the only network myc makes»).
Подкоманда проверяется только у команд-групп — иначе `myc import-beads snapshot` (позиционный
аргумент) ловился бы как выдумка.

## Живые прогоны

**Порча счётчика.** `myc doctor --recount` до порчи — exit 0; `UPDATE nodes SET open_blockers = 7`
руками через sqlite3 → exit **5**, `РАСХОЖД open_blockers: ws1-wpw92knc7snc: в базе 7, пересчёт 1`.

**Порча замыкания.** `DELETE FROM parent_closure WHERE depth=2` → exit **5**,
`нет строки ws2-ww0sh5kyqa2g→ws2-7bb3p4dx1735@2`; строк в таблице до запуска 2, после запуска 2 —
doctor не починил.

## Находки за границами задачи (не правил, как велено)

Сторож нашёл **два реальных обещания несуществующих команд**. Оба внесены в `KNOWN_MISSING`
с причиной и адресом; тест требует убирать строку, как только долг закрыт.

1. **`myc link` в `packages/cli/src/hooks/templates.ts`** (`skillMd()`): SKILL.md, который
   `myc wire` кладёт КАЖДОМУ агенту, велит писать
   ``myc link A supersedes B --reason "..."``. Команды `link` в реестре нет.
   Это инструкция агенту, а не комментарий, — цена выше остальных.
2. **`myc route` в `packages/cli/src/commands/prime.ts:566`** (help): «`myc route` — отдельная
   команда (S12)». Команды нет.

Ещё: `HOOK_SPECS` содержит событие `stop` на команду `myc close-session`, которой нет ни в одной
сборке. `myc wire` его намеренно пропускает, `doctor --hooks` показывает как «н/д» — это не
поломка, но событие `stop` не работает ни у кого.
