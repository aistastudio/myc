# Отчёты агентов

Рабочие отчёты, которые агенты писали по ходу задач (`REPORT-*.md`, ранее
лежали в корне репозитория). Каждый — не архивный текст, а измерения,
на которые ссылаются задачи в `myc`/`bd`: латентность конкретной операции,
результат бенчмарка, разбор конкретного инцидента. Источник правды по
дизайну — `docs/design/`; здесь — сырые данные и разборы, из которых
дизайн-документы и решения (`myc recall`) были построены.

Не удалять и не сокращать без переноса цифр в задачу или память проекта —
иначе ссылка "см. REPORT-X" в описании задачи перестанет что-либо значить.

Имя файла обычно совпадает с id задачи или её коротким слагом
(`REPORT-<slug>.md`) — ищите по нему через `myc show <id>` или `grep -l`
по содержимому.
