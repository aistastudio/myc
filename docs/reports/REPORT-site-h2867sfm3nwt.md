# memory-h2867sfm3nwt — сайт на GitHub Pages

Сайт: `site/`, публикуется действием `.github/workflows/pages.yml` на
<https://aistastudio.github.io/myc/>. Языки: английский (основной) и русский.

## Откуда публикуется и почему

**Из `site/` действием `actions/upload-pages-artifact` + `actions/deploy-pages`.**
Не из `docs/` и не из ветки `gh-pages`.

- `docs/` занят: восемь документов проектирования и 36 отчётов. Режим Pages «из
  папки /docs» опубликовал бы это как корень сайта и потребовал бы
  `docs/index.html`; Jekyll ещё и попытался бы обработать markdown отчётов.
- Ветка `gh-pages` — вторая копия содержимого в истории плюс ручной шаг
  публикации, который однажды забудут.
- Действие оставляет ОДИН источник и, главное, даёт прогнать `site/build.ts`
  прямо в публикации: **расхождение числа с артефактом замера роняет шаг
  сборки**, и сайт с неверным числом наружу не выходит.

## Главное требование: числа

Числа живут в `site/measurements.json` — по записи на величину, у каждой поле
`command`. `site/build.ts` сверяет их с артефактами репозитория и выпускает
`site/data.js`; `app.js` не содержит ни одной константы о продукте, всё рисуется
из данных. Сейчас **66 сверенных утверждений**, расхождений 0.

Скрипт поймал два расхождения при первом прогоне, и оба оказались настоящими:
`cache/embed/ratio` (отношение печатает тест по неокруглённым временам — теперь
сверяется попадание отношения в интервал, допустимый напечатанной точностью) и
`latency/read/drift` (мой порог был строже, чем у `scripts/bench-latency.ts`;
исправлено на ТО ЖЕ правило: 15% по p95 применяются, только если абсолютный
прирост ≥ 5% бюджета).

## Сравнения: у каждого инструмента названо, в чём он лучше

- **beads 1.0.5** — его очередь готовых задач **корректнее нашей**: `bd ready`
  наследует блокеры вниз по parent, `myc ready` нет; 144 против 195 на одном
  графе, открытый баг `memory-atcm254ry6c7`. Плюс релиз 1.0 против 0.1.1, Go без
  Bun, синхронизация через Dolt.
- **graft 0.16.0** — строит настоящий граф вызовов, `graft callers` отвечает
  точными рёбрами; myc на это не отвечает вовсе (M3 — 3 из 9).
- **Заметки в markdown** — ноль установки, дифф в пул-реквесте, переживают
  исчезновение любого инструмента из таблицы, включая myc.

Инструменты, которых мы не мерили (memora, socraticode), в таблицу не попали, и
на странице сказано почему.
